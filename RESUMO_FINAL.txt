## 🚀 Funcionalidades

| Recurso | Descrição |
|---------|-----------|
| **Upload** | Selecione uma imagem do seu computador |
| **Preview** | Veja a foto em tempo real (140x140px) |
| **Validação** | Apenas imagens, máx 5MB |
| **Persistência** | Salvo em localStorage, persiste após reload |
| **Avatar Padrão** | Mostra primeira letra (ex: "A" para Admin) |
| **Temas** | Funciona com todos os temas (dark/light/green) |
| **Feedback** | Mensagens de sucesso/erro |
| **Estado** | Botão mostra "Enviando..." durante upload |

## 🧪 Como Testar

### Passo 1: Acesso
```
URL: http://localhost:5173/perfil
(Faça login se necessário)
```

### Passo 2: Localizar
- Role até "CONFIGURAÇÕES"
- Procure por "📷 Foto de Perfil"
- Deve estar entre "Tema" e "Preferências"

### Passo 3: Teste de Upload
- Clique em "[⬆️ Escolher Foto]"
- Selecione uma imagem do seu PC
- Veja a foto aparecer no preview
- Mensagem: "Foto de perfil atualizada com sucesso!"

### Passo 4: Teste de Persistência
- Recarregue a página (F5)
- Foto deve continuar lá ✅

### Passo 5: Teste de Validação
- Tente selecionar arquivo .pdf → Erro ❌
- Tente selecionar imagem >5MB → Erro ❌
- Apenas imagens válidas funcionam ✅

### Passo 6: Teste de Temas
- Mude o tema para "Claro"
- Painel se adapta às cores claras ✅
- Mude para "Verde"
- Painel se adapta às cores verdes ✅
- Mude para "Escuro"
- Painel se adapta às cores escuras ✅
